# Third-party files stored with the app

These files are copied into the app so it works fully offline. Each keeps its own licence.

| File | Name and version | Licence |
|---|---|---|
| `lib/bootstrap.min.css`, `lib/bootstrap.bundle.min.js` | Bootstrap 5.3.3 | MIT |
| `lib/qrcode.min.js` | qrcode-generator 1.4.4 | MIT |
| `lib/html2pdf.bundle.min.js` | html2pdf.js 0.10.1 (includes html2canvas and jsPDF) | MIT |
| `lib/jszip.min.js` | JSZip 3.10.1 | MIT or GPLv3 (see the header inside the file) |
| `fonts/inter-*.woff2` | Inter (via @fontsource/inter 5.3.0) | SIL Open Font License 1.1, `fonts/OFL-Inter.txt` |
| `fonts/noto-sans-devanagari-*.woff2` | Noto Sans Devanagari (via @fontsource/noto-sans-devanagari 5.3.0) | SIL Open Font License 1.1, `fonts/OFL-NotoSansDevanagari.txt` |

`fonts/fonts.css` declares the fonts for the app.
